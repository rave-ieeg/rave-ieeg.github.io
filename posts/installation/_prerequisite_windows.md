These instructions are for Windows 10 with "bash" enabled. You will be asked many questions by the installers; the default response is fine for all of them.

### 1. Install the latest version of the R language

Go to [https://cran.r-project.org/bin/windows/base/](https://cran.r-project.org/bin/windows/base/){target="_blank"} and download the latest R. 

Open the installer and click through to install

### 2. Install the latest version of RTools.

Go to [https://cran.r-project.org/bin/windows/Rtools/](https://cran.r-project.org/bin/windows/Rtools/){target="_blank"} and download a proper version of `RTools`. The version must match your version of R. RTools contains compilers used to compile packages

### 3. (Optional) Install Node.js for AI features

If you want to use RAVE's AI features (optional, see [Drive RAVE with AI](../ai-agents/introduction.md){target="_blank"}), install `Node.js`.

Go to [https://nodejs.org/en/download](https://nodejs.org/en/download){target="_blank"}. The page selects the latest LTS (long-term support) version for you. Click "Windows Installer (.msi)" to download the installer.

Open the installer and click through to install. The default options are fine.
